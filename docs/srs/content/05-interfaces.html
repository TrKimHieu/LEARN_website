5. Yêu cầu giao tiếp (Interface Requirements)

5.1 Giao diện lập trình ứng dụng (API / RESTful Contracts)

Hệ thống chưa xuất tài liệu Swagger/OpenAPI; nguồn sự thật của hợp đồng API là Zod schema trong packages/contracts/src/*.ts (dùng chung cho validate phía API và form phía web) cùng các controller trong apps/api/src/modules. Bảng dưới liệt kê toàn bộ 54 endpoint.

Quy ước chung

API conventions
Hạng mụcQuy ước
Base URL{API_URL}/api/v1 (dev: http://localhost:4000/api/v1). JSON UTF-8.
Xác thựcAuthorization: Bearer <accessToken>. Refresh token chỉ đi qua cookie httpOnly refresh_token; web gọi với credentials: "include". CORS chỉ cho APP_URL và localhost:3000.
Public (không cần token)/auth/register, /auth/login, /auth/refresh, /auth/forgot-password, /auth/reset-password, /plans, /health, /health/ready, /webhooks/stripe (NFR-SEC-11).
ValidationBody/param/query qua Zod; schema body dạng strict — field lạ bị từ chối. ID là UUID.
Định dạng lỗiRFC 7807: { type, title, status, code, detail, requestId?, meta? }. type = https://learn.ai/errors/{code-lowercase}, suy ra từ code ở một chỗ cho mọi nhánh lỗi. Client so khớp bằng code, không bằng detail.
Request IDMọi response có header X-Request-Id (lấy từ request nếu client gửi, không thì sinh UUID). Màn hình lỗi của web hiển thị requestId.
Phân trangCursor-based: ?limit=&cursor= → { items, nextCursor } (đang áp dụng cho lịch sử học tập). Các danh sách nhỏ trả mảng trong object bọc ({ courses }, { lessons }…).
Rate limitRedis INCR + TTL theo userId/IP + route. Vượt → 429 RATE_LIMITED. Header X-RateLimit-*/Retry-After (NFR-OPS-02): Đang phát triển.
Security headershelmet (CSP tắt vì API thuần JSON).
